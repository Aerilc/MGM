# 政策监测 · 机会雷达（麦果麦）

每小时自动抓取北京市及国家部委公开政策信息，按「机会雷达」行动状态分类呈现：

- 数据来源：北京市经信局、市科委、市发改委、经开区、通州区、北京市政策兑现专区、工信部中小企业局梯度培育平台、工信部政策文件库与文件公示等 14 个公开来源
- 更新方式：GitHub Actions 每小时运行一次抓取并重建页面（`build.py`），数据状态保存在 `data.json`，页面为 `docs/index.html`，由 GitHub Pages 发布
- 「更新」页按每条信息的**首次发现日期**逐天分组、只增不删；发现日期随 git 提交历史永久保存

页面功能（雷达屏 / 全库 / 来源 / 更新、搜索、收藏）均为纯前端实现。
